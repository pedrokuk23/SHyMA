SHyMA Reviewer Workbench

Runs the SHyMA source code of the manuscript in your browser (Python via Pyodide). Use the paper's inputs to reproduce its results, or change them to explore.

A case fills the inputs of one tab with the values used in the paper (the same files as cases/*.json in the repository); press the tab's Run button and compare with the expected values listed here.

1σ dispersions (Table 2)

About 1–3 s per run in the browser. With the paper's seed, sequence and dispersions, the first N runs are exactly the first N runs of the paper (Supplementary Fig. S4); N = 1000 reproduces Table 6.

VSB-30 held-out validation (Sec. 5.2, Fig. 2, Table S19)

The model, calibrated on flight V01, predicts the apogee and range of the ten VSB-30 flights from payload mass, site, elevation and azimuth. About 1–4 min.

NASA NESC atmospheric check-cases (Sec. 5.1, Table S2)

Cases 5, 9 and 10 (spheres) and 17 (two-stage rocket). The browser compares altitude (and speed for case 17) with the NASA reference simulations embedded in this file; the paper's table also covers other variables. About 1 min.

Vehicle geometry

Body of revolution: one station per line, x r in metres from the nose tip (straight segments between stations). Fin sets: one per line, name x_le c_root c_tip span x_tip_offset n (exposed root chord, tip chord and span; tip leading edge aft of the root leading edge; n panels equally spaced). The default is the estimated VSB-30 full stack (Supplementary Material, S2-H).

Stability derivatives and drag

Component build-up as in NASA TM X-287 (Walker and Wolowicz, 1960): slender-body theory for the body, Diederich (subsonic) and linear theory (supersonic) for the fins, Pitts–Nielsen–Kaattari interference (NACA Rep. 1307), strip estimate of Cmq (per qd/2V). Per radian, referred to the reference area and diameter. Small angle of attack, no shock interference.

Formula checks

Each line evaluates a model function of the code and compares it with an independent reference value (standard tables or a hand evaluation of the equation in the paper).

About this file

This page embeds the SHyMA package (shyma/), the case-study, Monte Carlo and validation scripts, the VSB-30 flight table, the reference data of the NESC check-cases needed here, and the published results used for comparison. It runs them with Pyodide, a Python interpreter compiled to WebAssembly. Nothing is sent to a server.

Differences from running the repository with CPython: runs are serial instead of parallel; the Clopper–Pearson interval uses a pure-Python inverse incomplete beta function instead of SciPy (identical to 10−10); the bootstrap of the ellipse axis skips an unused term. Floating-point results can differ from the published ones in the last digits.

To reproduce every number of the paper, run ./run_all.sh in the repository. The SHA-256 hashes below can be compared with HASHES.sha256.
